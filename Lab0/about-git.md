\# Отличие ветки Git от копии папки с проектом



\- \*\*Организация на диске:\*\* При создании копии создается физический дубликат папки, что увеличивает объем занимаемой памяти и загромождает файловую систему. Ветка Git — это виртуальная ссылка; файлы проекта остаются в единственной папке, а их содержимое мгновенно переключается через терминал.

\- \*\*Слияние изменений:\*\* Объединение кода из копий папок выполняется вручную, что приводит к ошибкам. В Git слияние веток (`git merge`) происходит автоматически, сохраняя изменения из обеих версий и точно указывая на конфликты строк.

\- \*\*История и контроль:\*\* Копия папки не хранит информацию о том, кто, когда и зачем изменил код. Ветка содержит полную историю коммитов с комментариями авторов, позволяя откатиться к любому этапу работы.

\- \*\*Безопасность разработки:\*\* Эксперименты в отдельной ветке полностью изолированы и не могут случайно повредить стабильную версию проекта в основной ветке. В случае неудачи ветку можно удалить одной командой.

\# Что произойдёт с историей, если удалить папку проекта, но сохранить ​​​​.git​​​​?

\- \*\*История полностью сохранится:\*\* Вся база данных проекта, коммиты, авторы и ветки лежат внутри папки `.git`. 

\- \*\*Потеряются только некоммиченные файлы:\*\* Пропадут лишь те изменения, которые вы не успели сохранить через `git commit`.

\- \*\*Файлы легко вернуть:\*\* Чтобы восстановить всю структуру проекта из папки `.git`, достаточно выполнить в терминале команду `git restore .`.

\# Зачем нужен Pull Request, если можно коммитить сразу в main?

\- \*\*Контроль качества (Code Review):\*\* Препод или тимлид могут проверить твой код перед тем, как он попадет в главную ветку, и оставить замечания прямо к строчкам.

\- \*\*Безопасность main:\*\* Защищает стабильную версию проекта от случайных багов и сломанного кода, который может уронить всё приложение.

\- \*\*Тестирование (CI/CD):\*\* Позволяет автоматически запустить тесты и проверки кода именно для твоих изменений до того, как они сольются с основным проектом.

\- \*\*История и обсуждение:\*\* Создает удобное место на GitHub для обсуждения фичи, где видно всю хронологию правок, связанных с конкретной задачей.
